# Glossário

- **Análise:** execução imutável do workflow para uma proposta.
- **Decision pack:** conjunto versionado de perguntas, opções, rubricas e limiares usados com JEV.
- **Dossiê:** saída estruturada e narrativa entregue ao chatbot.
- **Evidence item:** registro de origem, coleta e conteúdo que sustenta uma conclusão.
- **Coverage Index:** proporção ponderada de pilares com dados válidos.
- **Confidence Index:** medida operacional da confiabilidade do conjunto de evidências; não é probabilidade garantida de sucesso.
- **Viability Score:** composição versionada de sub-scores de potencial.
- **JEV:** modelo System One da TypeSafe AI para decisões tipadas.
- **LLM generativa:** modelo usado para criação e síntese de texto.
- **Adaptador institucional:** implementação que traduz dados de um CRM para contratos canônicos.
- **Shadow mode:** execução paralela sem influência sobre a decisão real.
- **White-label:** configuração por instituição sobre o mesmo código-base.
