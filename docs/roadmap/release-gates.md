# Gates de release

## Gate A — Foundation ready

- Configuração validada.
- Migrations e rollback testados.
- Jobs idempotentes e retomáveis.
- Logs sem segredos.

## Gate B — Data ready

- Contratos ENS aprovados.
- Reconciliação com amostra oficial.
- Dicionário e qualidade documentados.

## Gate C — AI ready

- Decision packs avaliados.
- Modelo JEV pinado.
- Limiares definidos por dados.
- LLM passa testes de factualidade e injection.

## Gate D — Score ready

- Resultado-alvo definido.
- Backtest temporal concluído.
- Baseline superado conforme critério acordado.
- Shadow mode sem impacto operacional.

## Gate E — Integration ready

- Contratos REST/MCP versionados.
- Webhook idempotente e assinado.
- E2E com chatbot em staging.

## Gate F — Production ready

- Threat model revisado.
- Backup/restore testados.
- Alertas e runbooks ensaiados.
- Aprovação do responsável técnico, produto e ENS.
